# Mitwirken

1. Einen aussagekräftigen Dateinamen verwenden.
2. Skills und Prompts als Markdown im passenden Ordner ablegen.
3. Zweck, Voraussetzungen, Ablauf, Grenzen und Beispiel dokumentieren.
4. Keine geheimen Schlüssel, persönlichen Daten oder vertraulichen Inhalte committen.
5. Änderungen vor dem Commit auf Links, Rechtschreibung und sachliche Richtigkeit prüfen.

Neue Inhalte sollen eigenständig, nachvollziehbar und wiederverwendbar sein.
