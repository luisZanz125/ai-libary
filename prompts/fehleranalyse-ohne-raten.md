# Fehleranalyse ohne Raten

Analysiere den folgenden Fehler: **[LOG / FEHLERBESCHREIBUNG]**

Liefere:
1. Eine kurze Einordnung der Fehlermeldung.
2. Die wahrscheinlichste Ursache mit Belegen aus dem Log.
3. Sichere Fakten getrennt von Hypothesen.
4. Eine möglichst kleine, konkrete Korrektur.
5. Schritte zur Überprüfung und mögliche Nebenwirkungen.

Erfinde keine Testergebnisse. Falls Informationen fehlen, nenne genau, welche.
