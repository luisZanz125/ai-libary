# AI Library — PROMPTVERSE

Eine mobile-first Bibliothek für KI-Skills, Prompts, Agents und Workflows.

## Projektziel

Eine zentrale, übersichtliche Sammlung, die auf Smartphone, Tablet und Desktop funktioniert. Skills und Prompts sollen leicht gefunden, kopiert, bearbeitet und erweitert werden können.

## Bereiche

- **Skills:** wiederverwendbare Anweisungen und Fähigkeiten für KI-Agenten
- **Prompts:** Vorlagen für Recherche, Coding, Lernen und Kreativität
- **Agents:** Rollen, Aufgaben und Verhaltensprofile
- **Workflows:** mehrstufige Abläufe und Automatisierungen
- **Templates:** Startvorlagen für neue Projekte

## Anforderungen

- Responsive UI für Handy, Tablet und PC
- Suche, Tags, Kategorien und Favoriten
- Import und Export (Markdown/JSON)
- Lokale Speicherung mit späterer Option für Cloud-Synchronisierung
- Dokumentation und nachvollziehbare Versionshistorie

## Status

Grundgerüst und Inhalte werden schrittweise ergänzt. Noch nicht implementierte Funktionen werden ausdrücklich als geplant gekennzeichnet.

## Mitmachen

Neue Skills und Prompts sollen als Markdown-Dateien mit aussagekräftigen Namen abgelegt werden. Jeder Eintrag sollte Zweck, Voraussetzungen, Anleitung und ein kurzes Beispiel enthalten.

## Lizenz

Noch nicht festgelegt.
