# Code Review

## Zweck
Code auf Korrektheit, Sicherheit, Wartbarkeit und Verständlichkeit prüfen.

## Ablauf
1. Projektkontext, Sprache und Version erfassen.
2. Änderungen und betroffene Schnittstellen lesen.
3. Fehler, Randfälle, Sicherheitsrisiken und Regressionen suchen.
4. Findings nach Schweregrad sortieren.
5. Für jedes Finding Datei/Zeile, Auswirkung und konkrete Korrektur nennen.
6. Tests nur als ausgeführt markieren, wenn sie tatsächlich gelaufen sind.

## Qualitätsregeln
- Keine unbelegten Behauptungen.
- Stilhinweise von echten Bugs trennen.
- Vorhandene Konventionen respektieren.
- Keine unnötigen Komplettumbauten vorschlagen.
