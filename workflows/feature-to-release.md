# Workflow: Feature bis Release

1. Anforderungen und Akzeptanzkriterien festhalten.
2. Repository und bestehende Architektur untersuchen.
3. Technischen Plan und betroffene Dateien dokumentieren.
4. Feature in kleinen Schritten implementieren.
5. Tests und statische Prüfungen ausführen.
6. Fehler beheben und Regressionen prüfen.
7. Dokumentation und Changelog aktualisieren.
8. Release-Checkliste und bekannte Grenzen festhalten.
